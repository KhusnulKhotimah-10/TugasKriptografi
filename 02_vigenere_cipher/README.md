# Vigenere Cipher

Aplikasi sederhana Vigenere Cipher menggunakan Python.

## Fitur
- Enkripsi pesan
- Dekripsi pesan
- Kata kunci berulang sepanjang pesan
- Spasi dan tanda baca dipertahankan

## Konsep
Vigenere termasuk cipher substitusi abjad-majemuk. Setiap posisi menggunakan kunci yang berulang. Materi memberikan contoh kunci `LAMPION`.

## Cara menjalankan
```bash
python main.py
```

## Contoh
Plainteks: `KRIPTOGRAFIKLASIK`  
Kunci: `LAMPION`

Program akan menghasilkan cipherteks berdasarkan pergeseran huruf sesuai posisi kunci.
