# Columnar Transposition Cipher

Aplikasi sederhana Columnar Transposition Cipher menggunakan Python.

## Fitur
- Enkripsi pesan
- Dekripsi pesan
- Menggunakan kata kunci
- Kolom dibaca berdasarkan urutan alfabet kunci
- Karakter `X` digunakan sebagai padding jika diperlukan

## Konsep
Cipher transposisi mengubah posisi huruf pada plainteks tanpa mengganti hurufnya. Materi menjelaskan Columnar Transposition Cipher dan penggunaan kata kunci untuk menentukan urutan pembacaan kolom.

## Cara menjalankan
```bash
python main.py
```

## Contoh
Kata kunci: `TOMBAK`

Pesan dapat disusun ke dalam kolom, kemudian kolom dibaca sesuai urutan alfabet huruf pada kata kunci.
