# Tugas 3 Aplikasi Cipher Klasik

Tugas ini berisi tiga aplikasi cipher klasik berbasis Python:

1. Caesar Cipher
2. Vigenere Cipher (cipher substitusi abjad-majemuk)
3. Columnar Transposition Cipher

Setiap aplikasi memiliki fitur enkripsi dan dekripsi.

## Struktur
- `01_caesar_cipher/`
- `02_vigenere_cipher/`
- `03_columnar_transposition/`

## Persyaratan
- Python 3.x

## Menjalankan
Masuk ke salah satu folder, kemudian jalankan:

```bash
python main.py
```

## Dasar materi
Ketiga aplikasi dibuat berdasarkan materi kuliah "Ragam Cipher Klasik (Bagian 1)".
